# Zetormuseum

Apart Next.js-project voor de museumwebsite. **Raakt SitePilot (`atelier-solenne`) niet aan.**

## Lokaal

```bash
cd ~/Desktop/zetor-museum
npm run dev
```

Open: [http://127.0.0.1:3001](http://127.0.0.1:3001)

## Terug naar SitePilot

Open in Cursor de map `~/Desktop/atelier-solenne` (File → Open Folder), of zeg in de chat dat je terug wilt naar SitePilot.

SitePilot draait meestal op poort **3000**; dit museum op **3001**.
